# BatchMark

แปะลายน้ำรูปและวิดีโอทีละชุด ตั้งค่าครั้งเดียว ทุกไฟล์ได้ลายน้ำตำแหน่งเดียวกัน ขนาดพิกเซลเท่าต้นฉบับ
ทุกอย่างประมวลผลในเครื่อง ไม่มีการอัปโหลดรูปหรือวิดีโอไปที่ไหน

## ทำอะไรได้

- ลายน้ำแบบข้อความ (ฟอนต์ไทย) หรือโลโก้ PNG ปรับขนาด ความเข้ม หมุน ปูทั้งไฟล์ได้
- ตั้งขนาดและตำแหน่งแยกระหว่างไฟล์แนวนอนกับแนวตั้ง ปุ่มลัด 5×3 / 3×5 หรือลากวางเอง
- ล็อกการตั้งค่าทีละค่าได้ (ไอคอนแม่กุญแจ)
- รูป: บันทึกเป็น JPG / PNG / WebP คงขนาดเดิม
- วิดีโอ: รับ MP4 / MOV / WebM ออกเป็น MP4 เลือก codec ได้ (ตามต้นฉบับ / AVC / HEVC) เสียงคัดลอกไปตรง ๆ เมื่อทำได้
- ติดตั้งเป็นแอปบนมือถือและคอมได้ ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก

## ขึ้น GitHub Pages

1. สร้าง repo ใหม่ชื่อ `BatchMark` (Public)
2. กด **Add file → Upload files** แล้วเลือกทุกไฟล์ในโฟลเดอร์นี้ขึ้นไปพร้อมกัน (ทุกไฟล์อยู่ชั้นเดียว ไม่มีโฟลเดอร์ย่อย) แล้ว Commit
3. ไปที่ **Settings → Pages** ตรง Source เลือก **Deploy from a branch**, Branch `main`, โฟลเดอร์ `/ (root)` แล้ว Save
4. รอ 1–2 นาที แอปจะอยู่ที่ `https://<username>.github.io/BatchMark/`

หรือใช้ git:

```bash
git init
git add .
git commit -m "BatchMark"
git branch -M main
git remote add origin https://github.com/<username>/BatchMark.git
git push -u origin main
```

## ติดตั้งเป็นแอป

- **iPhone / iPad (Safari):** เปิดลิงก์ → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป**
- **คอม (Chrome / Edge):** กดไอคอนติดตั้งที่ช่อง URL

บนมือถือ หลังใส่ลายน้ำเสร็จจะมีปุ่ม **บันทึก / แชร์** เปิด share sheet ให้เลือกบันทึกลงคลังรูปได้ทีเดียวทุกไฟล์
บนคอมไฟล์จะดาวน์โหลดเป็น ZIP หรือทีละไฟล์

## อัปเดตแอป

แก้ไฟล์แล้วเปลี่ยนค่า `VERSION` ใน `sw.js` (เช่น `batchmark-v7`) ทุกครั้ง เครื่องที่ติดตั้งไว้จะได้เวอร์ชันใหม่เมื่อเปิดแอปครั้งถัดไป

## ข้อจำกัดของวิดีโอ

- ทำงานดีสุดบน Chrome / Edge บนคอม บนมือถือคลิปยาวหรือ 4K อาจทำไม่ผ่านเพราะแรมไม่พอ
- วิดีโอต้องเข้ารหัสใหม่ทั้งคลิป และวิดีโอ HDR จะออกมาเป็น SDR
- การเข้ารหัส HEVC ขึ้นกับเครื่อง ถ้าเครื่องทำไม่ได้แอปจะใช้ codec อื่น (ปกติคือ AVC) แทนและแจ้งให้รู้
